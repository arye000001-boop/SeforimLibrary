# ספרייה קטנה (seforim.db מדגמי)

סקריפט + workflow שבונים מתוך הספרייה המלאה (סכמה 7) קובץ `seforim.db` קטן:

* ספרים שלמים בלבד, נבחרים בחמדנות כך שיכסו את מגוון הקטגוריות, סוגי התלות (פירוש/תרגום/מדרש/מדריך),
  סוגי הקישורים, מקורות, טעמים, ניקוד, מבנים חלופיים, גרסאות והערות.
* קישור נשמר רק אם **שני** הספרים שלו בדגימה, כך שכל המפתחות הזרים תקינים והמפרשים באמת עובדים.
* מזהים (id) נשארים כמו במקור. הגודל מכויל בבנייה בפועל.

הרצה: Actions ← "Build sample library" ← Run workflow. התוצאה ב-Releases של המזלג.

שימוש: לשנות שם ל-`seforim.db` ולהניח בתיקיית הספרייה של אוצריא (הוראות מלאות בתשובה בצ'אט).
